## Overview

This directory contains TypeScript configuration definitions for the application. At the root level there is a single file, app.config.ts, which defines a centralized application configuration object (appConfig). That object collects configurable settings across multiple areas of the application such as sandbox/E2B behavior, AI model options, code application behavior, UI settings, development flags, package installation preferences, file management, and API endpoint configuration.

Because this directory provides a single, authoritative source for runtime and build-time options, other parts of the system import values from the app.config.ts object to ensure consistent behavior. There are no subdirectories; the flat structure emphasizes that this directory's sole responsibility is configuration declaration. Developers should treat this directory as the canonical place to find and update application-wide settings and to understand available configuration options that affect sandboxing, AI model choices, UI toggles, developer tooling flags, installation preferences, file handling, and API endpoints.


### File Organization

All configuration is consolidated in a single TypeScript file (app.config.ts). This flat layout makes it straightforward to locate and update global settings without navigating multiple files or folders.

## Architecture Notes

- Configuration is centralized in a single TypeScript module (app.config.ts) to provide a clear, authoritative source of truth for application settings.
- TypeScript-based configuration allows compile-time checks and safer refactors for consumers that import the configuration object.

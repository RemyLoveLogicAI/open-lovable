## Overview

This directory contains grouped API route implementations organized by feature. At the root level there are no standalone files; instead, each subdirectory holds a single TypeScript route implementation (route.ts) that implements the request handling logic for a specific API endpoint. The routes present are focused on AI-powered code workflows: analyzing edit intents, applying AI-generated code, and generating AI code in a streaming fashion. Each subdirectory's root TypeScript file is the entry point for that route and is responsible for receiving, processing, and responding to HTTP requests targeted at that endpoint.

Collectively, the subdirectories provide a cohesive set of server-side endpoints used by the application to support code analysis, transformation, and streaming generation workflows. The analyze-edit-intent route handles intent analysis requests; apply-ai-code handles applying AI-suggested code changes; and generate-ai-code-stream orchestrates SDKs, streaming utilities, and repository/file selection helpers to enable streaming outputs. Together these components enable client code to interact with AI-assisted code editing and generation features within the larger system.


### File Organization

Each feature or API endpoint is placed in its own subdirectory. Each subdirectory contains a single TypeScript route implementation (route.ts) that acts as the entry point for that endpoint. There are no root-level route files in this directory; instead, routes are grouped by their specific API surface area.
